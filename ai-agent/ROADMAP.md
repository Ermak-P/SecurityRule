# План развития .NET AI Агента

## Фаза 1 — Стартер (готово ✅)

Базовая версия агента с консольным интерфейсом и инструментами файловой системы.

**Что уже реализовано:**
- Запуск Ollama в Docker
- Консольный интерфейс (ввод/вывод)
- Tool Calling (вызов инструментов из LLM)
- Инструменты: `list_files`, `read_file`, `write_file`, `create_file`, `search_in_files`
- История разговора в рамках сессии
- Защита от выхода за пределы директории проекта

---

## Фаза 2 — Умный анализ кода

Добавить понимание структуры .NET проектов на уровне кода, а не только файлов.

**Задачи:**
- Интеграция **Roslyn** (Microsoft.CodeAnalysis) для разбора C# кода
- Новые инструменты:
  - `get_class_info` — структура класса (поля, свойства, методы)
  - `get_usages` — где используется класс/метод
  - `get_dependencies` — зависимости через DI / using
  - `patch_method` — изменить только один метод (не весь файл)
- Понимание `.csproj` (NuGet пакеты, таргет-фреймворк, зависимости проектов)
- Интеграция с `dotnet build` — проверка что код компилируется после изменений

---

## Фаза 3 — Улучшение агента

Сделать агента умнее и приятнее в работе.

**Задачи:**
- **Streaming ответов** — показывать ответ LLM по мере генерации (как в ChatGPT)
- **Planning mode** — перед выполнением агент составляет план и показывает его пользователю
- **Сохранение сессий** — история разговора сохраняется между запусками
- **Multi-agent** — несколько специализированных агентов:
  - Агент-аналитик (читает и анализирует)
  - Агент-кодировщик (пишет и изменяет код)
  - Агент-ревьювер (проверяет что написал кодировщик)
- **Отмена действий (Undo)** — откат изменений файлов
- Улучшенный системный промпт с примерами

---

## Фаза 4 — Интеграции

Подключить агента к инструментам разработчика.

**Задачи:**
- **Git интеграция** — показывать diff изменений, создавать коммиты
- **Web UI** — простой браузерный интерфейс (например на Blazor или Vue.js)
- **MCP сервер** — [Model Context Protocol](https://modelcontextprotocol.io/) для интеграции с VS Code / Cursor
- **LSP интеграция** — анализ ошибок компилятора и их автоматическое исправление
- **Запуск тестов** — `dotnet test` и анализ упавших тестов

---

## Фаза 5 — Продвинутые функции (готово ✅)

Сделать агента максимально полезным для реальной разработки.

**Что реализовано:**
- **RAG (Retrieval-Augmented Generation)** — ChromaDB + Roslyn-чанкинг ✅:
  - ChromaDB запускается через `docker compose up -d`
  - Roslyn разбивает .cs файлы на чанки (метод / класс / интерфейс)
  - Коллекции разделены по слоям: `code-domain`, `code-infrastructure`, `code-web`, `code-tests`
  - Инкрементальная переиндексация по SHA256 хешу файла
  - Метаданные: layer, file, member, member_type, entity, file_hash
  - `semantic_search` поддерживает фильтрацию по слою
- **Автоматическая генерация тестов** ✅:
  - `generate_tests` — NUnit [Test] / [TestFixture], паттерн Returns_X_When_Y
  - Автоматически выбирает unit vs integration (репозитории → InMemory AppDbContext)
  - `generate_feature` — SpecFlow .feature файлы на русском языке для Blazor E2E
- **Несколько моделей (роутинг)** ✅:
  - Быстрая модель (`--fast`) для поиска/объяснений
  - Умная модель (`--smart`) для кода/ревью/рефакторинга
  - Автоматическая классификация задачи по ключевым словам
